# SapinSapin TTS over WebSocket

A minimal streaming text-to-speech endpoint for hardware and embedded clients.
Send a line of text, get raw PCM back as it is synthesized.

    wss://sapinsapin-tts-ws.hf.space/tts

The audio format is fixed and header-free so a microcontroller can hand frames
straight to a DAC:

| | |
|---|---|
| Encoding | PCM S16LE (signed 16-bit, little-endian) |
| Sample rate | 16000 Hz |
| Channels | 1 (mono) |
| Container | none — no WAV header, no framing of our own |
| Frame size | 3200 bytes (100 ms) |

Full contract, error strings, and client pseudocode:
[`docs/AGORA_INTEGRATION.md`](docs/AGORA_INTEGRATION.md).

## Protocol

```jsonc
// client sends one text frame
{"text": "Magandang umaga po sa inyong lahat."}

// server sends binary frames of PCM, then exactly one terminal text frame
{"type":"end"}
// or, on failure
{"type":"error","message":"..."}
```

Optional fields, both safe to omit — a client that sends only `text` behaves
identically:

```jsonc
{"text": "Maayong buntag sa tanan.", "lang": "ceb", "voice": "CEB_0200"}
```

`lang` accepts a code (`fil`) or a display name (`Filipino`), case-insensitive.
`voice` accepts a speaker id, a gender, or an index. `GET /` lists what this
instance is serving.

## Models

Synthesis is `sapinsapin/speecht5_tts-pld-<lang>` (SpeechT5 finetuned on the
Philippine Language Dataset) with the `microsoft/speecht5_hifigan` vocoder, and
a precomputed x-vector for speaker conditioning. These checkpoints emit 16 kHz
natively, so nothing is resampled. Revisions are pinned by commit sha in
`prefetch.py` and baked into the image.

They are **baselines**, trained on prompted read speech in controlled sessions.
Two consequences worth knowing before judging the output:

- **Write numbers as words.** The training text contains no verbalized
  numerals, and the tokenizer silently discards characters it cannot encode —
  `₱500` does not become "five hundred pesos", it disappears. Dropped
  characters are logged.
- Each sentence is synthesized independently, so there is no intonation
  carried across sentence boundaries.

## Running it elsewhere

The server is host-agnostic; only the launcher changes.

```bash
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 7860 --ws websockets \
  --ws-ping-interval 20 --ws-ping-timeout 60 --workers 1

# and to give a remote client a public URL without deploying:
cloudflared tunnel --url http://localhost:7860
```

Hugging Face Spaces only exposes `wss://` on port 443. A client that cannot do
TLS with SNI needs a host that serves plain `ws://` on its own port instead.

## Verifying

```bash
python tools/ws_client.py ws://localhost:7860/tts "Magandang umaga po."
python tools/ws_protocol_test.py ws://localhost:7860/tts
python tools/ws_probe.py wss://sapinsapin-tts-ws.hf.space/tts   # host viability
```

`ws_client.py` writes `out.wav` and checks the things that fail silently
otherwise — frame alignment, byte order, clipping, and implausible duration.
Listen to the file anyway; no assertion hears intelligibility.

## Configuration

Every limit is an env var; see `settings.py`. The ones most likely to need
changing for a given device:

| Env | Default | Why you would change it |
|---|---|---|
| `SERVE_LANGS` | `fil,ceb,hil` | Languages to load. Must be pinned in `prefetch.py` first. |
| `CHUNK_BYTES` | `3200` | Drop to `1024` for a small receive buffer. Must stay even. |
| `PACE_FACTOR` | `0` | Set `1.0` to drip frames at realtime instead of as fast as the transport drains. |
| `MAX_TEXT_CHARS` | `500` | Longer requests are rejected, never truncated. |
| `TTS_TOKEN` | unset | Requires `?key=<token>` on the socket URL. Off for the first demo. |
