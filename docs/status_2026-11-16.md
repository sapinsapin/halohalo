## Where things stand, in one screen

**ASR.** Unchanged since 09-25. `whisper-large-v3-pld-<lang>-norm` is the
recommended model for nine languages (CER 4.6–16.0 %, WER 12.2–30.7 %, frozen

**TTS.** The headline claim of the 09-25 status was withdrawn on 2026-09-26
(`c1a0852`). Re-transcribing the *same saved audio* with Meta's MMS-1b-all
instead of our PLD-trained Whisper judges nearly reverses the ranking:
MMS-TTS wins seven languages, Orpheus wins Cebuano, Kapampangan ties. Neither
judge is neutral — ours was finetuned on the recordings Orpheus learned from,
MMS-1b-all comes from the project that made MMS-TTS — so **the comparison is
unresolved until people listen**. What survives both judges: Orpheus is
intelligible, is the only Tausug TTS, and SpeechT5 is far behind; the untrained
Qwen3-TTS base beats MMS-TTS on Cebuano and Kapampangan under both. The same
run also settled the MMS-TTS Cebuano puzzle (17.8 % then 42.9 % CER): on the
later sentences with the earlier judge it is 16.1 % — the judge moved it, not
the model.

**Data.** The web flywheel ran to the end of its Tavily credit: **56,689
documents / 25.42M words after 24 rounds and purges**, up from 22,303 / 11.96M
after round 2. An audit found a machine-translation farm posing as Cebuano

Across the run the gate rejected far more retrains than it promoted, which is
the gate working.

**Porting.** New since 09-25 and the largest body of work in the window. The
pipeline in `porting/` exports each model with the toolchain that reaches a
target and checks it against PyTorch on the same held-out clips: **367
model–target ports, 224 in Phase 1, 143 in Phase 2**. Phase 1 is validated on
every runtime this machine can run, with a published "what to ship per target"
rule (smallest artefact within 0.5 CER points of PyTorch). Two results worth
keeping: `halo-lid` in the browser is *bit-identical* to Python (95.6 % both,
max probability difference 0), and the Cebuano CTC model goes from 3.67 GB to
971 MB at int8 for +0.07 CER. Details: `docs/porting_report.md`.

### Noise, not work

`git status` lists **241 modified files**. Only the 13 above have content
changes. The rest is environmental:

- `core.autocrlf = true` against a tree written with LF, so Git considers
  ~160 text files modified on line endings alone.
- `core.filemode = true` across a Windows/WSL boundary, so 66 files differ
  only in their permission bit, including every `.npy` and sample `.wav`.

`git diff --numstat --ignore-cr-at-eol -w` is what tells the truth here. Worth
fixing once with a `.gitattributes` (`* text=auto eol=lf`) and
`core.filemode false`, so the next person does not have to rediscover it.

## What the RTX 3070 can and cannot do

Unchanged from 09-25, with one correction: that status assumed "~6 GB free
with the desktop running". Measured just now, **5.6 GB of the 8 GB is held by
desktop applications** (Chrome, Spotify, the game launchers, Parsec,
TeamViewer). Plan for ~2.5 GB unless those are closed first, and check
`nvidia-smi` before starting anything.

Two failures from the window are now understood and belong in any local plan:

- **L5 hung for 2.5 days** at step 0. DataLoader workers pass tensors through
  a Unix socket in `$TMPDIR`; `/mnt/d/tmp` sits behind WSL's 9P bridge, which
  refuses sockets (`OSError: [Errno 95]`). Point `TMPDIR` at WSL-native disk
  for multi-worker jobs, or keep `--num-proc 1`.
- **L6 failed** before step 0: transformers has no SDPA attention for
  `Wav2Vec2BertForCTC`. `finetune_ctc.py` now forces eager attention for it.

The disk rule stands: C: is small and a full C: took WSL down three times on
2026-09-17. Keep venvs, `PIP_CACHE_DIR`, `TMPDIR` and `HF_HOME` on D:.
